## Contract, dependencies and boundaries

Add a version-1 job request with requested stages, inline stage policies, optional
sizing-history/decision-evidence input files, explicit decision effective time, model
policy/scope. Freeze file contents into the run specification, never reread mutable
request files on resume. Existing publisher policy defaults are validated and frozen
in full; no statistical thresholds or budgets are silently changed. Explicit sizing
history revisions may reference a verified pinned predecessor publication.

Fixed topological stages: sizing history → sizing diagnostics → within-filter
discovery → prioritization → configuration sheets; visuals depend on diagnostics;
queues depend on discovery/prioritization/sheets/visuals; models depend on visuals.
Canonical/atlas inputs are existing mandatory core stages. Model fitting is an
independent `--fit-models` opt-in, never caused by ordinary refresh or a model stage
name alone. Missing model opt-in or sheet effective time blocks affected optional
stages visibly, including dependants. An absent sizing ledger uses the existing
explicit empty-history audit with run cutoff, not invented Kelly history. Absent
sheet evidence uses the builder's existing unknown-setting sheet behavior.

Final optional-job manifest records frozen request/code/source identities, DAG,
completed/blocked/not-requested stage receipts and artifact hashes. Reused optional
checkpoints must match dependency receipts and pass existing artifact readers.
Any requested builder exception prevents new final result publication. Independent
immutable artifacts may survive for resume; they do not activate a dashboard report.
All selected stages (including blocked stages) must reconcile with final receipts.

No upload UI, scheduler, export automation, dashboard activation, inference-policy
change, new economic calculation, account/service connection or deployment. R09/R10
retain upload/preview/activation; R11/R12 retain UI. R07 context is preserved as a
separate selection contract: job execution does not refit based on display selections.
