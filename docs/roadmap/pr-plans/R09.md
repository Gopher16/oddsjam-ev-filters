## Behavior and contract

Before: manual CSV import immediately archives a local file. After: an additive
private staging API/CLI accepts a bounded binary stream, validates CSV extension,
UTF-8 and existing required schema, and publishes an immutable version-1 preview.
No import, build, report activation or study launch occurs on staging. Filename
is display-only, rejected if it contains traversal separators. Store directories
and source files are owner-only. Fixed limits bound bytes, rows and columns.
Formula-like text is retained literally and counted; no spreadsheet export or
formula evaluation occurs. Preview contains counts, schema, raw date bounds and
explicit full/partial/unknown declaration, never inferred freshness or coverage.

Preview reuses load_observations/reconcile against the current private store and
synthetic candidate observations to distinguish unchanged, revised, new and
unresolved rows. Settlement/status changes are separately counted. Receipt pins
prior import identities; confirmation recomputes preview and requires its digest,
so changed store contents force another review. Import uses existing import_csv
under the existing lock and namespace/content idempotency. Stage ID includes
source and metadata, excluding filename. Verify staged hashes on every read.
