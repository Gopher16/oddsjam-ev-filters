## Contract and scope

Opt-in trusted local configuration enables an accessible CSV picker/drop zone,
explicit acquisition metadata, bounded R09 staging and reconciliation preview.
Confirmation launches one local subprocess using a fixed entry point, never a
user command or path. Show durable stage events; cooperative cancellation stops
at stage boundaries and before publication. Retry uses the same frozen request
and snapshot, preserving verified pipeline checkpoints. Stale previews require
review again. Imports already committed cannot be undone by cancellation.

New reports are verified before explicit activation. Builds, failures, cancellation
and repeated uploads never silently replace the selected report. An initially
empty catalogue also requires activation. Display source/export/receipt cutoff
separately from generation time. Snapshot reanalysis is descriptive, not a claim
of complete or fresh history. No scanner, model fit, experiment launch or live
execution is triggered. Default deployed/read-only dashboard remains unchanged.

## Compatibility, rollback and risks

No source schema/metric change. Version-1 job receipts are separate from published
research contracts. Trusted local-only opt-in, private job/staging directories;
no credentials in uploads/logs. Disable refresh configuration to roll back UI;
immutable old reports remain selectable. Subprocess cancellation is cooperative,
not a hard kill mid-write. Crash recovery/retry must not create a new source cutoff.
Do not extend to shared hosting without a separate storage/auth/worker design.
No material baseline deviation planned; unresolved browser acceptance is a merge gate.
