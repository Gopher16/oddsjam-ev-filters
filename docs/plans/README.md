## Ready to use versus optional development

The supported dashboard workflow is ready for candidate review and preparation of
future paper studies. There is no further mandatory planned feature PR after J–M
before that use. A specific setup may still need evidence before launch, and an empty
queue is an acceptable research result.

Optional chronological evaluation of the newer within-filter family, combined build
orchestration, remaining chart forms, threshold/calibration studies and supported
outside-universe or bankroll scenarios are separately scoped work. Missing historical
source timing, liquidity or scanner settings cannot be repaired by relabeling a plan.
See the [remaining-work ledger](MULTIDIMENSIONAL_IMPLEMENTATION_STATUS.md#remaining-work-and-its-next-action).

Private/local roadmap notes are outside this public documentation index and its
tracked-file checks. Do not move or publish them as part of archival maintenance.
