## Publication and coverage rules

All rows have public disposition **text reference only**; public image/hash is
unavailable, no redacted derivative or owner publication review is claimed. Before
adding an asset, inspect the entire original and derivative for financial/account
and unrelated browser information, preserve a private source identifier, use a
reviewed synthetic/redacted illustration, record provenance/review and meaningful
alt text, and obtain owner confirmation where release requires it. Never commit
raw account screenshots, even if attached for planning. Existing synthetic operator
images show a different workflow and cannot prove tracker acceptance.

Global Search/Ask QPB/Rewards navigation labels appear across captures, but no
assistant answer, search result or rewards workflow is supplied. TRK11's grounded
assistant and TRK07's promotion inventory are proposals. Merchandise/recruitment/
social links are vendor-specific: retain useful support/profile/preferences rather
than replicate marketing destinations. Logos/scores/player media require supported
sources/assets. Positive/negative colors need non-color accessible equivalents.

Each region must retain a delivered, planned, conditional or explicitly accepted
equivalent disposition at N014. Presently every tracker feature is planned or
conditional; N001 delivers documentation only. This catalogue adds no original
OddsJam A–G figure, does not renumber its slots, and grants no account or live-order
access. [Original operating references](../oddsjam-workflow/README.md) remain intact.
