# Synthetic dashboard image provenance

These four PNGs show the current dashboard using only fictional data generated by
[operator_demo.py](../../examples/operator_demo.py). They were captured at the
`monitor` stage of the [operator walkthrough](../../walkthroughs/README.md), with
240 historical synthetic wagers, two prospective paper observations and one
subsequent paper-monitoring observation. No private source records, account images
or generated research publications are included.

[capture_synthetic.mjs](../../examples/capture_synthetic.mjs) drives an isolated
local Chrome profile at 1440 × 1000. It selects the synthetic parent filter and
captures overview, complete setup, study economics and reviewed lifecycle sections.
The visible fictional-data watermark is added during capture, not by the dashboard.
The walkthrough includes the exact reproduction commands and prerequisites.

- `overview.png`: candidate queue and production concerns.
- `setup.png`: complete scanner parameter sheet and setting states.
- `paper-study.png`: version-linked paper economics and captured observations.
- `lifecycle.png`: reviewed modifications, applications and subsequent monitoring.

All images intentionally remain synthetic documentation assets. Long identities
and scrollable tables reflect the current interface; inspect the attached publication
or download its parameter sheet for complete values. These screenshots do not
establish profitability, promotion eligibility or actual external application.
